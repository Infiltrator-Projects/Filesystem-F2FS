# Filesystem-F2FS

Native Common V2 offline reader development. Recognition verifies redundant superblock geometry and complete checkpoint-pack CRCs. The new reader selects the newest complete clean checkpoint, uses native NAT/SIT shadow bitmaps and checkpoint journals, reconstructs live allocation counts, validates node identity and provides bounded stat/list/read through ordinary and inline directories and direct data mappings. Initial mount scope excludes feature extensions, multi-device/zoned layouts, checkpoint payloads, dirty recovery, external xattrs and higher indirection. The [exact development qualification](https://github.com/Infiltrator-Projects/Filesystem-F2FS/actions/runs/46131738008) passed independent empty and populated media, exact payload comparison, hosted/import-free builds and sanitizers. The v0.1.0 native package candidate installs `/System/Filesystems/F2FS.so` and `/System/Resources/Documentation/Filesystem-F2FS.pdf`; publication requires exact-revision CI and reconstructed native package tests. The v0.0.1 PDF-only release remains immutable. No write, format, repair, defragmentation or physical BOOT/kernel qualification is claimed.
